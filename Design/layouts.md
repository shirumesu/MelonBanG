# 布局

## 应用框架

```
┌──────────────────────── 标题栏 44 ─────────────────────────┐
│ ◧ ←                [ ⌕ 搜索番剧          Ctrl F ]     ☾ — ▢ ✕ │
├──────────┬─────────────────────────────────────────────────┤
│ 侧栏 208 │ 内容区（左右边距 24）                            │
│ 探索     │                                                 │
│ 追番 27  │                                                 │
│ 缓存     │                                                 │
│ …        │                                                 │
│ 设置     │                                                 │
│ 账户卡片 │                                                 │
└──────────┴─────────────────────────────────────────────────┘
```

- 标题栏：左侧折叠侧栏、返回；中间全局搜索（Ctrl / ⌘ F 聚焦，聚焦时显示最近搜索）；右侧主题和窗口按钮。macOS 左侧给红绿灯留 78px。
- 侧栏在所有页面（包括设置）保持不变；播放器例外，进入时默认收起（可用标题栏按钮展开），窗口全屏或显示屏全屏时完全隐藏。
- 侧栏数字只在有意义时显示：追番显示在看数量，缓存只在有任务下载时显示“N 下载中”。
- 页面不再有大标题页头。

## 页面模板

| 模板 | 页面 | 结构 |
| --- | --- | --- |
| 仪表盘 | 首页 | 上下两段，每段左右分栏，右栏固定 336 |
| 网格 | 追番、搜索结果 | 筛选 / 标题行 + 海报网格（每列约 184 宽） |
| 详情 | 番剧详情 | 上段：主面板（封面、信息、操作、剧集格）+ 右栏 336（我的收藏、收藏统计）；下段：左侧人物与吐槽，右栏作品资料与关联 |
| 表格 | 查找资源、缓存 | 表单 + 固定在顶部的筛选栏 + 列表行 |
| 设置 | 设置 | 内容区内左侧分类列（约 200），右侧分类标题 + 设置行 |

## 窗口宽度

默认窗口 1360×860，最小 960×640。

- 首页内容宽度不足 860 时，右栏折到下方：聚光灯独占一行（榜单隐藏，用左右箭头切换），今日更新改为固定高度 460 放在最下面。
- 资源表格宽度不足 760 时，来源分组 / 大小 / 发布合并成行内一行文字。
- 设置页内容宽度不足 820 时，分类列收窄到 176。
- 番剧详情内容宽度不足 860 时，右栏取消：我的收藏与收藏统计在主面板下方并排（不足 600 时上下排列），下段改为单栏，作品资料与关联排在吐槽之前。
- 搜索框宽度为“标题栏宽度 − 两侧按钮”，最大 420。
