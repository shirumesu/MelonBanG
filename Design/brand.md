# 品牌

源文件在 [brand/](brand/)：`logotype.svg`（标准字标）、`logotype-flat.svg`（无描边）、`icon.svg`（白底图标）、`icon-bare.svg`（无底图标，Windows）、`icon-macos.svg`（macOS 图标网格）。应用图标和安装器里的字标 PNG 都由这些文件导出。

## 字标

- 粗圆单线字形，整体 8° 斜体，外加白色描边和深绿投影（`#0F5C46`）。
- 双色：Melon 薄荷绿 `#22B388`，BanG 珊瑚色 `#FF6B81`，正好分开 Melon 与 Bang(umi)；G 的右上角一颗金色星 `#FFB83D`。
- 「o」由角色顶替，保持直立，不跟字母一起倾斜。
- e、a 的字腔要留够：e 的横笔更细、略低，右下开口；改字形时先确认描边后字腔仍然看得清。
- 应用内、小尺寸用无描边版。

## 角色

圆角三角加两颗白色胶囊眼睛，灵感来自 Grok 的头像。刻意简单、谁都能画，没有语义，不扮演表情。

动作只靠形状、颜色和弹跳（实现见 `installer/lib/bot.dart`）：

| 状态 | 动作 |
| --- | --- |
| 待机 | 呼吸、眨眼、偶尔瞟一眼 |
| 进行中 | 在三角、圆、方、花、四叶、卵石之间变形并慢慢转 |
| 完成 | 跳起转一圈 |
| 出错、警告 | 变珊瑚色，横向抖一下 |
| 等待 | 褪成 `#8CBFAE`，闭眼慢呼吸 |
| 移除中 | 边变形边缩小 |
| 告别 | 跳两下 |

- 所有形状都是按角度取样的半径函数，任意两个可以逐点过渡；切换状态时形状和颜色平滑过渡，不直接换图。
- 会转向鼠标：身体按指针方向做透视倾斜，眼睛偏向指针。等待和移除中不跟随。
- 系统关闭动画时显示静止姿态。

## 图标

- Windows：无底的角色（`icon-bare.svg`），32px 以下照样可认。
- macOS：白色圆角方块上的角色，按 1024 网格留边并带轻投影（`icon-macos.svg`）。
