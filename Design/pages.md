# 页面

每个页面按“用户来这里最想做的事”排序。

## 首页（探索）

1. **聚光灯（左上）**：本季热度当前一名，模糊封面做背景，显示排名、番名、原名、评分、标签、简介和“查看详情”。左右箭头在 #1–#8 之间循环。
2. **榜单（右上）**：#1–#8 文字列表和刷新按钮；点击切换聚光灯，当前项高亮。前三名的序号用 coral。
3. **继续观看（左下）**：先列最近播放的条目（左上“第 N 话”角标、右上“剩余 N 分钟”角标、底部进度条），点击进入番剧详情；再列在看的番。两种卡片下方都是评分和“已看 N/总话数”，今天有更新的排在前面并标“今日更新”。标题不带统计副标题。
4. **今日更新（右下）**：标题旁显示“已更新 N/总数”。按播出时间排列的时间线，每行只有番名和“已更新 / 待更新”。早于当前时间的条目圆点实心、线条和时间为主色，并标“已更新”；之后的是空心圆点、灰色、“待更新”。中间有 coral 的“现在 HH:MM”标记，打开时自动滚动到它附近，每 30 秒刷新一次。在追的番标“在追”。

时间统一按上海时间（UTC+8）显示，与放送表一致。

## 搜索

- 标题栏搜索框：聚焦时下拉显示最近 8 条搜索（保存在本机，可清除），输入时按包含关系过滤。
- 结果页：标题“‘关键词’ 的搜索结果”，副标题“N 部”，海报下方显示“年份 · 话数”以区分续作和剧场版。滚动到底部自动加载下一页；结果太少无法滚动时显示“加载更多”按钮。

## 查找资源

查找资源页、播放器资源弹窗和“手动选择资源”对话框是同一个界面：同一次搜索同时查本地缓存、在线源和 BT 资源站，表单、筛选和结果行完全一致。弹窗和对话框把关闭、“在页面中打开”放在顶部说明行右侧；“在页面中打开”带着当前关键词、筛选和结果进入页面。同一作品同一话的表单与筛选在三处共用。

1. 顶部一行：封面缩略图、番名，指定集数时下方写“第 N 话”。
2. 搜索表单（决定“去资源站搜什么”，改了要重新搜索）：关键词（框内右侧是“别名 N”下拉，勾选一起搜的别名）、集数、搜索按钮。关键词和别名同时用于在线源和 BT 资源站，集数只用于 BT。搜索中在表单下方显示进度条和“正在搜索 N/M 个资源站”（各站结果数和失败在资源站下拉里看）；在线站点失效或需要验证时在表单下方给出原因和“打开站点”。
3. 筛选栏（只在已有结果里本地筛选，立即生效；两层，滚动时一起固定在顶部）：第一层是“全部 / 本地 / 在线 / BT”分段控件（各带数量；本地包含已完成和缓存中的 BT / PikPak 任务），有筛选时右侧显示“筛选后 N 条”，填了集数搜索时最右是“批量下载”（清空集数重新搜索，结果按资源分组后再选集数）；第二层是资源站（在线站点与 BT 资源站）、画质、字幕组、字幕（语言：简体 / 繁体 / 日文；形式：内封 / 内嵌 / 外挂）四个多选下拉，然后是清除筛选。同一下拉内任一项满足即可，不同下拉之间要同时满足；“简体”包含简繁、简日双语。标题没写某项的资源（没有画质、字幕组或字幕信息）不筛掉，排在确定符合的资源之后，并补一个“未标明字幕组”之类的说明。
4. 结果行约 60px：第一行标题（点击整行展开完整原名和“打开发布页”；需要选集的在线结果标题不带“选择集数 / 选择分 P”，靠展开箭头表示），第二行全是标签：“推荐”（当前列表排第一的确定匹配，主色实底）、类型、集数（合集写“合集 01–12”）、画质 / 片源 / 编码 / 字幕、补充信息（时长、联合署名、下载进度，无底色）和提醒（可能匹配、最近播放失败、站点失效、画质不确定、集数范围有误，tertiary 色）。右侧列为“来源”（字幕组或线路，下面是资源站）、大小、发布日期，没有的值显示“—”，然后是 BT 的下载分体按钮和播放按钮。表头只写“资源 / 来源 / 大小 / 发布”。同一资源站的同一个种子只有一行，补充到字幕组后原地更新。BT 只有指定了集数、或整部作品搜索时对应到本作某一话才能播放（边下边播）。填了集数（能对应到本作某一话，如“03”“S01E03”“第3话”，续作也可写总集数）时只搜这一话：写着别的集数的 BT 单集、不含这一话的合集都不显示，在线站点直接列出这一话的条目；集数为空或认不出时按整部作品搜索。排序：缓存优先，在线 / BT 按设置的优先级；同类中确定匹配在可能匹配之前，近期播放失败的靠后，延续本作上一话的来源；这部番记住的来源（上次播放的站点线路，或 BT / PikPak 的字幕组）优先于全局优先级，同站点或同字幕组次之，完全一致的行带“上次选择”补充标签；其余按画质优先的综合分：画质（4K > 1080p > 720p > 未标明）为主，再加首选字幕语言、内封优先、BD > WEB-DL > WebRip 片源、HEVC 编码，以及与同画质资源相比大小是否适中（过大或过小都扣分）；集数冲突和指定单集时的合集大幅降分。
5. 需要选择的在线结果（整部作品搜索时的站点作品、B 站投稿）和资源分组用同一种行：标题、“在线”、读到条目后的覆盖集数（“第 1–12 话”，或“N 个条目”）、站点说明和提醒，来源列是线路；操作列是“批量下载”（先读条目，再按能对应最多话的那条线路选集数；单集搜索时没有）。展开后在浅底面板里列出条目，多条线路时每条线路先有一行线路名，右侧是这条线路的“批量下载”；每个条目一行，写站点的集名，整部作品时按集名对应到本作章节，对应不上的标“未对应本作剧集”、不能下载播放。可能匹配的结果播放前先确认。
6. 资源分组（集数为空时，即整部作品搜索或清空了集数）：同一资源站上同一字幕组同一系列的单集资源合成一行，可展开。是否同一系列看标题开头署名的字幕组、季、画质、字幕语言与形式、片源和编码标签、流媒体平台（ABEMA、Baha、CR 等）；标题其余部分各集常有出入（“招募翻译”“1920x1080”、别名增减），不参与。字幕的写法也会变（LoliHouse 前两集写“ASSx2”，之后写“[简繁内封字幕]”），所以没写字幕的那几集并入这一系列唯一一种写了字幕的分组；写了几种字幕的（如简日、繁日分开发）仍各成一组。分组行第一行是去掉集数的标题，第二行是“推荐”、类型、覆盖的集数（“第 1–12 话”，按本作话数）和最佳那集的标签；右侧来源、合计大小（每话取一个）、最新发布日期，操作列合成一个“批量下载”按钮。展开后各集按话数排列在缩进的浅底圆角面板里（面板左缘对齐分组标题），每集一行约 40px：展开箭头（点击显示原标题和“打开发布页”）、“第 03 话”（本作话数），只列与分组行不同的东西（标题写的集数与本作不同时补“标题为第 38 话”、画质不确定等提醒），右侧沿用表格的大小、发布列和下载、播放按钮；字幕组、画质、编码等已在分组行上的不再重复，“推荐”只标在分组行。合集、特别篇、没写字幕组的资源和在线结果不分组。集数对应本作：续作的资源常按跨季总集数编号（第二季第 1 话写成 [29]、03(51)），所以续作里没写季的资源按 Bangumi 的总集数对应，写了季的按季内集数或总集数对应，写了别的季的不对应；对应不上本作任何一话的（多是前几季）排在最后，标“未对应本作剧集”，不能批量下载。单个未成组的资源序号与本作不同时补一个“对应第 N 话”。
7. 批量下载对话框：资源说明（字幕组与标题、资源站与画质字幕），“集数”输入框写区间（“1-3, 5, 8-12”，右侧全选 / 清空），下面每话一个格子：可选为描边、选中为主色实底、这个资源没有的那话灰底不可点、已从这里加入缓存的打勾不可点、已有其他缓存的右上角小圆点（默认不选）；点击格子增减，按住 Shift 点击选连续一段，输入框与格子互相同步，操作说明在标题旁的 ? 图标。确认按钮“下载 N 集”，每话下载该资源里排名最高的那一个，按资源类型走 BT 或 PikPak。

集数和别名放在搜索表单而不是筛选栏：它们改变的是发给资源站的请求，放进筛选栏会让人以为点了就生效。

## 设置

设置是一整页，不分页、不折叠，所有设置项在一个滚动区域里按分区排列，以后新增的设置放进对应分区即可，不加二级页面或要连点的入口。

- 左侧是“设置”标题、搜索框和分区目录（图标 + 名称）：点击目录平滑滚到该分区，滚动时目录跟着高亮当前分区。搜索按设置名和同义词（如“硬解”“代理”“去重”）过滤到具体的行，分区名命中时显示整个分区；没有结果时显示“没有与 X 相关的设置”。
- 分区顺序：账户与同步、外观、播放、弹幕、资源选择、下载与做种、网络、存储、快捷键、更新与关于。每个分区是图标 + 标题，下面是一张或几张卡片；一个分区里有几组时，卡片上方用小号粗体写组名（如播放里的“播放 / 画面 / 字幕与音轨”）。
- 设置行左边是名称和必要的一句说明，控件在行尾；行宽不够时控件换到名称下方。较长的解释放在名称旁的 ? 里（硬件解码、超分辨率、做种方案、代理范围等）。开关行整行可点。
- 所有设置即改即生效，没有“保存”按钮。下载与做种的数字输入框在回车或离开输入框时校验并应用，不合法时输入框下方写原因、不保存；“恢复推荐值”是这张卡片的最后一行。原来的“高级设置”折叠区取消，分享和连接两组用组名直接列出。
- 外观：主题模式是“浅色 / 深色 / 跟随系统”分段；主题色是一排圆形色块（薄荷为品牌默认，另有海蓝、葡萄、樱花、橘子、墨灰）和一个“跟随系统强调色”的彩色圆块，选中的加描边和对勾；“封面取色”开关让番剧详情和播放器取这部番封面的颜色。标题栏右上角的主题按钮在浅色和深色之间切换（会离开“跟随系统”）。
- 播放：自动连播、自动标记为看过、自动跳过片头 / 片尾（只对内嵌章节认出 OP / ED 的视频）；画面组是硬件解码（自动 / 兼容模式 / 关闭）和超分辨率（关闭 / 效率 / 质量，Anime4K）；字幕与音轨语言。
- 资源选择：放送中 / 已完结番剧的来源优先级；“记住每部番的来源”（默认开）和“清除所有番剧的来源记忆”；“播放时缓存下一话”（默认关）。
- 弹幕：显示弹幕、字号 / 不透明度 / 显示区域滑块（数值在右侧）、速度与密度分段、合并重复弹幕、类型与样式芯片、恢复默认显示；屏蔽组是规则输入框和规则列表（启停开关、删除，无效正则标红）。
- 网络：代理（不使用代理 / 使用系统代理 / 自定义 HTTP 代理，说明里写当前实际走向），自定义时下方出现代理地址输入框；连通性测试一行“开始测试”，测试后逐项列出分组标签、服务名、延迟或原因（可连接为主色勾，只写延迟——探测不带登录信息，401 / 404 也算正常连上，不显示状态码；403 / 451 / 5xx 为金色提醒并写出状态码，失败为珊瑚色）。设置行标题旁的 ? 说明悬停时出现在问号右侧（窗口太窄时在左侧），不挡住下面的小字；说明写成两三行短句，不写长段落。
- 存储：图片与资料缓存（用量和清理规则合成一句，清理按钮）、应用数据和媒体缓存（用量、更改位置，路径在下方可复制）、刷新空间用量；有待迁移计划时在卡片底部显示。
- 更新与关于：版本与更新状态、自动检查 / 自动下载更新；开源许可；卸载 MelonBanG（Windows 关闭应用后打开卸载程序；macOS 确认框里可勾选“同时删除所有数据”，勾选后列出将删除的文件夹、按钮变成错误色“退出并删除全部”；便携版提示直接删除文件夹并提供“打开文件夹”；开发版本只写说明）。
- 账户：未登录时标题“未登录”，说明“登录 Bangumi 后同步收藏和观看进度”；登录后显示昵称和 @用户名，同步行只在登录后出现，标题是“N 项修改待上传”或“已全部同步”，失败时说明行写原因。
- 快捷键表与播放器实际按键保持一致（见下方播放器第 5 条），另列搜索番剧和返回。

## 播放器

播放器跟随应用主题，不再有“开灯 / 关灯”：想要暗的画面就切深色主题（标题栏右上角）。侧栏和资源弹窗跟随主题；浮在画面上的东西（控制栏、弹幕设置、倍速 / 字幕菜单、音量条、跳过片头、失败提示）在两种主题下都是深色半透明、白色文字和白色选中，不用薄荷绿——黑底配绿色显得生硬，主色只留在浅色的侧栏里。底色是中性黑（和控制栏渐变同色，不带蓝灰）；弹幕设置、倍速 / 字幕菜单和音量条是同一种毛玻璃：背后画面模糊、黑色半透明、一圈很淡的白色细边，不加阴影；选项选中时整行白底深色字，和弹幕设置里的分段选择一致。可视化方案见 https://claude.ai/artifact/D5KmBwWeXQShu5eUbVxSU4（采用方案 A）。

1. **画面优先**：进入播放器时主侧栏自动收起（标题栏左侧按钮可临时展开，只影响播放器）。右侧侧边栏在内容宽度 ≥ 1080 时默认展开，否则默认收起，由标题栏最右侧的侧边栏图标切换；全屏和窗口全屏时隐藏，退出后恢复。
2. **顶部**：番名（粗体）后面是较淡的“第 N 话 标题”，随控制栏淡入淡出，所有模式都显示。番名、进度条和播放键的图形左边缘都对齐在 24px，全屏键右边缘同样距右 24px。
3. **控制栏**：最上方是细进度条（悬停变粗、显示指针处时间、浅色显示已缓冲、已播放部分为白色）。视频内嵌章节里能认出 OP / ED 时，在 OP 结束和 ED 开始处各有一个小白点，悬停显示“01:32 OP 结束”，点击跳过去；认不出就不显示。播到 OP / ED 里时右下角出现“跳过片头 / 跳过片尾”；设置里开了自动跳过时，正常播进片头 / 片尾会直接跳到结尾并提示“已跳过片头”，每话只自动跳一次，拖动或续播落在片头里不跳。左侧：播放 / 暂停、上一帧 ‹• / 下一帧 •›（点了就暂停，暂停时连点保持暂停）、下一话、音量（指针停在喇叭上弹出竖向音量条和百分比，点喇叭直接静音，滚轮可调）、时间。右侧：弹幕开关（弹幕框图标，关闭时变淡并加斜线）、弹幕设置、倍速、字幕、窗口全屏、全屏。宽度不足 680 时右侧换到第二行。提示文字写成“播放 (Space)”“静音 (M)”，下一话只写“下一话”。
4. **反馈**：暂停时画面中央显示大播放按钮；快进、音量、弹幕开关等没有固定位置的操作，在画面上方短暂显示提示；按住 → 时持续显示“3× 快进中”。
5. **快捷键与鼠标**：单击画面播放 / 暂停，双击全屏；空格或 K 播放 / 暂停，← 快退 5 秒（按住连续，连按会累加），轻按 → 快进 5 秒、按住 → 三倍速播放直到松开（不改变记住的倍速），↑ ↓ 音量 ±5，Home 回到开头，M 静音，D 弹幕，F 全屏，Esc 退出全屏或关闭浮层。`,` 上一帧、`.` 下一帧，逐帧后暂停并显示毫秒时间；弹幕冻结，继续播放时按当前时间恢复布局。拖动或点击进度条后，进度条保持在目标位置直到播放器到达（网络流缓冲期间不闪回旧位置）。音量、静音和倍速状态会记住。
6. **侧边栏**（宽 336，窄窗口 296）：顶部番名、“第 N 话 标题”和“番剧详情”（回到详情页；从详情页进来的就返回那一页，返回时不经过已停止的播放器）。标为看过 / 未看在剧集格右键菜单里。下面是“剧集 / 讨论 / 弹幕”分段控件：
   - **剧集**：正在播放的资源卡（BT / PikPak / 在线等类型标签、字幕组或线路与画质、资源名、下载状态与进度，右上“换资源”；这部番记住了来源时，卡片底部一行书签图标“已记住 X”和“忘记”）；悬停那话（否则正在播放那话）的“第 N 话 标题”和状态；每话一个方格、六列（正在播放为主色实底加图标，已看为主色容器，已缓存右上角小圆点，下载中底部细进度条，未更新为灰底淡字），点击按来源规则播放，右键有播放、查找资源、标为看过 / 未看；本作的缓存任务折叠成底部一行“缓存任务 N 个”，展开后可暂停 / 继续、选择文件播放。原来的“选集 / 缓存”两个分段和每行的“资源”按钮取消。
   - **讨论**：Bangumi 这一话的吐槽，按楼层从早到晚，每条显示两条回复，其余“还有 N 条回复”；右上“在 Bangumi 打开”带外链图标。
   - **弹幕**：各来源的状态（条数或未匹配原因）和开关；点“更换 / 匹配”在该来源下原地展开候选和手动搜索；“导入弹幕 JSON”；屏蔽规则。
7. **资源弹窗**：底部浮层，内容即“查找资源”界面，顶部说明行右侧是“在页面中打开”和关闭。播放后关闭弹窗。播放中所有“换资源”的情况（侧栏换资源、点了没有现成资源的那话、可能匹配、播放失败）都打开这个弹窗，不会跳到别的页面。
8. **弹幕设置**（控制栏，深色浮层）：不透明度、字号、显示区域三个滑块，速度和密度两组分段，滚动 / 顶部 / 底部 / 彩色 / 描边 / 允许重叠 / 防挡字幕开关标签；底部“恢复默认”和“来源与屏蔽 ›”（打开侧栏的弹幕页）。不再有时间校准。
9. **字幕与倍速菜单**：和音量条一样，指针停在按钮上约 0.1 秒就在正上方弹出，移开后自动收起，选了一项也收起；点按钮同样可以开关。只有弹幕设置这类复杂浮层需要点击打开。字幕只列轨道（自动、各轨道、关闭字幕），不提供音轨和字幕时间偏移（音轨按设置里的语言偏好自动选）；倍速 2.0x–0.5x，点 1.0x 即恢复，没有单独的“恢复 1×”。
10. **失败**：选定的资源播放失败时不自动换成别的资源。在线资源先刷新一次地址；仍然失败就停下：还没有画面时显示原因和“重试 / 选择资源”，已有画面时暂停并在画面中央显示原因、“重试”和“选择其他资源”。
11. **自动连播**：右下角显示“N 秒后播放第 M 话”，下方小字是来源，提供“立即播放 / 取消”。没有可立即播放的来源时显示结束卡片及“查找资源”（打开资源弹窗）；主动操作或 Esc 取消。

## 番剧详情

首屏（1360×860）要看到基本信息、操作、剧集和受欢迎程度；评分之外的人气用收藏统计表达。

1. **主面板（左）**：封面、标题与 Bangumi 链接、原名、放送年月（如“2026年10月”；Bangumi 标签里的年月不再重复显示）/ 平台 / 前三个标签；评分、“排名 #N”与评分人数、已看进度条；“播放 / 继续播放 / 重看第 N 话”（主要操作）和“查找资源”（整部作品）；下一话还没播出时，主要按钮变灰、换时钟图标，写什么时候更新：一小时内“N 分钟后更新”，一周内“今天 / 明天 / 周X HH:MM 更新”（没有放送时间时省略时刻），更远写“10月25日更新”，播出时刻一到自动恢复为播放；简介默认三行，可展开。
2. **剧集格**：主面板下半部分，每话一个方格，三种状态：已看为主色容器；未看（已播出）为描边空心；未更新（还没到播出时刻：日期以 Bangumi 每话的播出日期为准，跳周也不会错；7 天放送表在这一天前后一天内有播出时，用它的时刻，否则按当天零点算）为 `surfaceContainerHigh` 灰底、无描边、文字变淡，表示还不能看。不再用实底高亮“下一话”：已看与未看的分界已经表明看到哪，实底容易被当成“已经可以看”。格子上不放进度条、当前集 / 下一集标记或缓存角标；看到的时间和是否已缓存都在标题行显示。点击时若该话有可播放的缓存（含可边下边播的 BT / PikPak 任务）直接进入播放，否则打开该话的统一资源列表；右键菜单提供播放、查看资源、标为已看 / 未看和关联本地文件；按住约 0.6 秒开始标记（已看的那话改为标未看），继续按住拖动选中从按下那话到指针所在那话的连续范围，往回拖即缩小，松开后一次保存。图例行（已看 / 未看 / 未更新）末尾是 ? 图标，悬停说明点击、长按和右键；标记过程中改为提示“已选 N 话，松开标为已看，Esc 取消”，拖出区域时为“松开将取消”；按右键、按 Esc 或拖出格子区域约 48px 外松开都会取消。超过四行时只显示下一话附近四行，可展开全部。标题行显示悬停那话（否则下一话）的“第 N 话 标题”，后面用空白隔开、以次要色显示看到的时间 / 未更新 / 已看、已缓存和播出日期；未看和未缓存不写。原“选集”弹窗已取消。
3. **我的收藏（右栏）**：收藏状态分段控件；十颗星评分，点击立即保存并可撤销、可清除；标签可删除，“+ 添加”弹出输入和热门标签，点一下即保存；吐槽预览，点击打开编辑抽屉。右上角“编辑”打开同一抽屉。保存反馈、撤销和失败原因在卡片底部原位显示；改为看过时顺带提供“剩余 N 话标为已看”。
4. **收藏统计（右栏）**：五种状态的比例条及人数、百分比。
5. **下段**：左侧角色与配音（每行最多四张紧凑卡片，前 8 位）、制作团队（职位与人名紧凑行，一人多职用顿号连接，前 12 位），超出用“全部 N 位”对话框；然后是吐槽 / 评论 / 讨论：每条信息行是用户名（正文色）、五颗星评分（Bangumi 的 10 分折成五星、半星步进，金色实星，空星为 `surfaceContainerHighest`，悬停显示“N 分 评语”）、收藏状态或回复数，日期贴右边对齐。吐槽完整显示（Bangumi 限 380 字，最多约九行，不折叠）；评论标题点开 Bangumi 日志，摘要最多三行，超出时断在后半段最后一个标点处加“…”，没有标点就在行尾直接截断；列表里只有日志前 120 字，下方“展开”时读取全文并原位显示，“收起”；讨论标题点开 Bangumi 帖子，下面是信息行和一楼正文（最多四行，可展开）；回复放在正文下的浅底框里，收起时只写“共 N 条回复，点击查看”，打开后按页显示，每页 10 楼，框底是“共 N 页 / 上一页 / 页码（当前页主色加粗，页多时只留首尾和当前页两侧，中间用 … ）/ 下一页 / 收起”，翻页或收起后若框顶已在视口上方就滚回框顶；每楼最多六行可展开，楼中楼挂在楼层头像下的竖线后缩进，先显示 3 条，“还有 N 条楼中楼”展开其余，楼号写“#2 / #2-1”。正文的 BBCode 保留粗体、斜体、下划线、删除线，剧透涂黑，引用变淡，图片写“[图片]”，其他标签和表情去掉。右栏是作品资料（前 10 项，可展开）和关联作品（按前传、续集、番外、总集篇、其他分组的小封面列表，前 6 部；关系与分组名相同时不再重复）。

**收藏状态是前提。** Bangumi 不接受未收藏条目的评分、标签、吐槽和章节进度：没有状态时点评分、标签或吐槽，状态控件抖动并描边，卡片底部提示先选择状态；想看状态不能评分时同样提示；切到想看会清空 Bangumi 上的评分，但应用记住原分数，改回其他状态时自动恢复（仅本次运行内）。在剧集格里标记已看时，若尚未收藏会先自动加入“在看”。

**编辑抽屉**：从右侧滑出，宽 440，标题下只写番名，包含状态、评分、标签（输入 + 热门标签开关）、吐槽和“同时将全部正片标为已看”（仅看过）。抽屉以当前已保存的收藏为初值。关闭（× / Esc / 点击外部）会把未保存的修改暂存为草稿（本次运行内，按账号和条目区分），卡片标“有草稿”、按钮变“继续编辑”，再次打开时恢复并提示，可放弃草稿；“放弃修改”清除草稿；保存成功后清除草稿。

**我的吐槽**：已登录时吐槽分段顶部固定显示自己的吐槽：未写时是一行输入框，展开后可发布；已写时显示内容和“编辑 / 删除”，删除需在原位确认，只清空吐槽，评分、标签和状态保留。列表里不再重复显示自己的那条。

**播放**：在详情页点击播放立即进入播放器，显示封面、“第 N 话 标题”、“正在查找资源…”和“选择资源”；找不到或启动失败时原位给出原因和“重试 / 选择资源”。从资源列表选定候选播放时同样先进入播放器。

## 视频源

- 侧栏在缓存与设置之间提供“视频源”；仅启用来源失效时显示警示点。
- 两栏结构：左侧约 244px 的紧凑来源列表分为在线、BT 索引和网盘，名称、状态徽章和开关使用共用列表样式；右侧为详情。内容宽度不足 820px 时以列表进入详情。
