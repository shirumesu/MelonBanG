# 页面

每个页面按“用户来这里最想做的事”排序。

## 首页（探索）

1. **聚光灯（左上）**：本季热度当前一名，模糊封面做背景，显示排名、番名、原名、评分、标签、简介和“查看详情”。左右箭头在 #1–#8 之间循环。
2. **榜单（右上）**：#1–#8 文字列表和刷新按钮；点击切换聚光灯，当前项高亮。前三名的序号用 coral。
3. **继续 · 正在追（左下）**：先列可继续播放的条目（播放按钮、“继续第 N 话”、底部进度条），再列在看的番；今天有更新的排在前面并标“今日更新”。
4. **今日更新（右下）**：按播出时间排列的时间线。早于当前时间的条目圆点实心、线条和时间为主色，并标“已更新”；之后的是空心圆点、灰色、“待更新”。中间有 coral 的“现在 HH:MM”标记，打开时自动滚动到它附近，每 30 秒刷新一次。在追的番标“在追”。

时间统一按上海时间（UTC+8）显示，与放送表一致。

## 搜索

- 标题栏搜索框：聚焦时下拉显示最近 8 条搜索（保存在本机，可清除），输入时按包含关系过滤。
- 结果页：标题“‘关键词’ 的搜索结果 · N 部”，海报下方显示“年份 · 类型 · 话数”以区分续作和剧场版。滚动到底部自动加载下一页；结果太少无法滚动时显示“加载更多”按钮。

## 查找资源

1. 顶部一行说明：封面缩略图、番名、“下载将关联到第 N 话”。
2. 搜索表单（决定“去资源站搜什么”，改了要重新搜索）：关键词（框内右侧是“别名 · N”下拉，勾选一起搜的别名）、集数、搜索按钮。搜索中在表单下方显示进度和各资源站状态。
3. 筛选栏（只在已有结果里本地筛选，立即生效；滚动时固定在顶部）：资源站、画质、字幕组、字幕（语言：简体 / 繁体 / 日文；形式：内封 / 内嵌 / 外挂）四个多选下拉，然后是“含未标明”、清除筛选和结果计数。同一下拉内任一项满足即可，不同下拉之间要同时满足；“简体”包含简繁、简日双语。
4. 结果行约 60px：第一行标题（点击整行展开完整原名和原始发布链接），第二行集数标签在前、其余标注在后；右侧是来源分组、大小、发布日期和下载分体按钮。

集数和别名放在搜索表单而不是筛选栏：它们改变的是发给资源站的请求，放进筛选栏会让人以为点了就生效。

完整查找资源页保留下载搜索与筛选；播放器的资源弹窗使用下述分段候选列表。

## 设置

- 左侧分类：账户与同步、界面与外观、播放、缓存方式、下载与做种、应用数据。
- 右侧顶部是分类名，下面是分组标题和设置行；按钮和开关在行尾。
- 播放分类提供字幕与音轨语言偏好、自动连播、放送中与已完结番剧的来源优先级，以及复用播放器的弹幕显示和屏蔽设置。
- 下载与做种的“保存并应用 / 恢复推荐值”固定在底部，表单在上方滚动。

## 播放器

播放器跟随应用主题。浅色主题下控制栏有“开灯 / 关灯”按钮（L）：开灯时与其他页面一样是浅色，关灯时标题栏、侧栏和选集栏一起变暗，让画面成为最亮的部分。默认开灯，之后记住上次的选择，不另设设置项。深色主题下本来就是暗的，不显示这个按钮。

开关灯和应用主题是两件事：主题按钮在标题栏，开关灯只在播放器的控制栏，避免两个按钮挨在一起被误按。整个窗口的主题变化（切换主题、进入关灯的播放器、开关灯）都用约 300ms 的渐变过渡，不会一下子变黑。

1. **画面优先**：进入播放器时主侧栏自动收起（标题栏按钮可临时展开，只影响播放器）；右侧选集栏在内容宽度 ≥ 1080 时默认展开，否则默认收起，由控制栏的“选集”切换。
2. **顶部**：番名和集数随控制栏一起淡入淡出，所有模式都显示。
3. **控制栏**：最上方是细进度条（悬停变粗、显示指针处时间、浅色显示已缓冲）。左侧：播放 / 暂停、下一话（按来源优先级选择可播放资源）、音量（图标 + 滑块，滚轮可调）、时间。右侧：“弹”开关、弹幕设置、倍速、字幕与音轨、开关灯（仅浅色主题）、选集、窗口全屏、全屏。宽度不足 680 时滑块隐藏、右侧换到第二行。
4. **反馈**：暂停时画面中央显示大播放按钮；快进、音量、弹幕开关等没有固定位置的操作，在画面上方短暂显示提示。
5. **快捷键**：空格播放 / 暂停，← → 快退 / 快进 5 秒，↑ ↓ 音量 ±5，M 静音，D 弹幕，L 开关灯，F 全屏，Esc 退出全屏或关闭浮层。`,` 上一帧、`.` 下一帧，逐帧后暂停并显示毫秒时间；弹幕冻结，继续播放时按当前时间恢复布局。音量、静音和倍速状态会记住。
6. **选集栏**（宽 336，窄窗口 296）：顶部番名、当前集数和“找资源”；有本作缓存任务时用分段控件切换“选集 / 本作缓存”。每集一行：集数方块（当前集为主色并显示播放图标，已缓存为实底，未缓存为描边）、标题、状态；点击章节按来源规则直接播放；每行“资源”打开分段候选列表。

7. **资源弹窗**：底部浮层使用“本地 / 在线 / BT / PikPak”分段控件并显示数量；分类第一项标“推荐”。在线显示站点、线路、匹配与健康状态，BT 保留字幕组、画质、语言、大小、发布时间和只下载的分体按钮。点击候选播放；完整下载搜索通过“完整资源查找”进入。
8. **弹幕设置**：显示、来源、屏蔽三组。显示组默认 25px、90% 透明度、60% 区域、普通密度，透明度范围 10–100%；四档密度最高档无同屏条数上限。来源包含默认开关、匹配与独立时间校准，屏蔽支持关键词和正则；无效正则原位标红。显示、屏蔽及来源默认开关本地保存，“恢复默认”仅恢复显示组。
9. **自动连播**：右下角显示下一话、来源与五秒倒计时，提供“立即播放 / 取消”。没有可立即播放的来源时显示结束卡片及查找资源入口；主动操作或 Esc 取消。

## 番剧详情

首屏（1360×860）要看到基本信息、操作、剧集和受欢迎程度；评分之外的人气用收藏统计表达。

1. **主面板（左）**：封面、标题与 Bangumi 链接、原名、年份 / 季度 / 平台 / 前三个标签；评分、排名与评分人数、已看进度条；“播放 EP N”（主要操作）和“查找资源”（整部作品）；简介默认三行，可展开。
2. **剧集格**：主面板下半部分，每话一个方格（已看为主色容器，下一话为主色实底，未播出文字变淡，已缓存右上角圆点）。点击打开该话的统一资源列表；右键菜单提供播放、查看资源、标为已看 / 未看和关联本地文件；按住约 0.6 秒开始标记（已看的那话改为标未看），继续按住拖动选中从按下那话到指针所在那话的连续范围，往回拖即缩小，松开后一次保存。标记过程中图例行改为提示“已选 N 话 · 拖动调整范围 · 右键或 Esc 取消”；按右键、按 Esc 或拖出格子区域约 48px 外松开都会取消。已缓存在图例中说明。超过四行时只显示下一话附近四行，可展开全部。悬停时标题行显示该话详情。原“选集”弹窗已取消。
3. **我的收藏（右栏）**：收藏状态分段控件；十颗星评分，点击立即保存并可撤销、可清除；标签可删除，“+ 添加”弹出输入和热门标签，点一下即保存；吐槽预览，点击打开编辑抽屉。右上角“编辑”打开同一抽屉。保存反馈、撤销和失败原因在卡片底部原位显示；改为看过时顺带提供“剩余 N 话标为已看”。
4. **收藏统计（右栏）**：五种状态的比例条及人数、百分比。
5. **下段**：左侧角色与配音（每行最多四张紧凑卡片，前 8 位）、制作团队（职位 · 人名紧凑行，前 12 位），超出用“全部 N 位”对话框；然后是吐槽 / 评论 / 讨论。右栏是作品资料（前 10 项，可展开）和关联作品（按前传、续集、番外、总集篇、其他分组的小封面列表，前 6 部）。

**收藏状态是前提。** Bangumi 不接受未收藏条目的评分、标签、吐槽和章节进度：没有状态时点评分、标签或吐槽，状态控件抖动并描边，卡片底部提示先选择状态；想看状态不能评分时同样提示；切到想看会清空 Bangumi 上的评分，但应用记住原分数，改回其他状态时自动恢复（仅本次运行内）。在剧集格里标记已看时，若尚未收藏会先自动加入“在看”。

**编辑抽屉**：从右侧滑出，宽 440，包含状态、评分、标签（输入 + 热门标签开关）、吐槽和“同时将全部正片标为已看”（仅看过）。抽屉以当前已保存的收藏为初值。关闭（× / Esc / 点击外部）会把未保存的修改暂存为草稿（本次运行内，按账号和条目区分），卡片标“有草稿”、按钮变“继续编辑”，再次打开时恢复并提示，可放弃草稿；“放弃修改”清除草稿；保存成功后清除草稿。

**我的吐槽**：已登录时吐槽分段顶部固定显示自己的吐槽：未写时是一行输入框，展开后可发布；已写时显示内容和“编辑 / 删除”，删除需在原位确认，只清空吐槽，评分、标签和状态保留。列表里不再重复显示自己的那条。

**播放**：点击播放立即进入播放器，显示封面、集数和“正在查找可播放资源”；找不到或启动失败时原位给出原因和“重试 / 手动选择资源 / 完整资源查找”。从资源列表选定候选播放时同样先进入播放器。

## 视频源

- 侧栏在缓存与设置之间提供“视频源”；仅启用来源失效时显示警示点。
- 两栏结构：左侧约 244px 的紧凑来源列表分为在线、BT 索引和网盘，名称、状态徽章和开关使用共用列表样式；右侧为详情。内容宽度不足 820px 时以列表进入详情。
- 顶部将页名与检查更新、全部测试放在同一行，规则版本、来源和更新时间作为次要文字。域名、引擎和浏览器入口合并在一个面板；分步诊断共用一个面板，每行显示结果与耗时，展开查看地址或失败原因。
- 手动搜索结果使用紧凑列表，播放入口按线路分组为按钮；选择后在原位解析和试播。诊断数据仅保留于本次运行。
