# Melonbang 设计语言

这里记录 Melonbang 桌面端界面的设计约定，改界面前先查这里，改完同步更新。代码里的唯一来源是 `lib/ui/core/theme.dart`，本目录解释这些数值该怎么用、为什么这样定。

| 文件 | 内容 |
| --- | --- |
| [foundations.md](foundations.md) | 颜色、字体、字号、间距、圆角、阴影、动效 |
| [components.md](components.md) | 共用组件及其用法 |
| [layouts.md](layouts.md) | 应用框架、页面模板、窗口宽度规则 |
| [pages.md](pages.md) | 各页面的结构与信息优先级 |

## 原则

1. **内容优先，首屏可见。** 默认窗口 1360×860 下，首页的四块内容（本季热度、继续播放、正在追、今日更新）都要出现在首屏。新增内容先想清楚它挤掉了谁。
2. **一层标题就够。** 标题栏不再写页面名，侧栏高亮表示当前位置；子页面（详情、查找资源、搜索结果）在内容顶部用一行说明上下文。
3. **丰富的封面，克制的界面。** 海报、彩色标签和评分负责“活力”；框架本身保持中性灰底、薄荷绿强调，不做大面积彩色背景。
4. **状态要看得出来。** 已更新 / 待更新、已隐藏的资源站、集数冲突等状态同时用颜色和文字表达，不只靠颜色。
5. **一致的位置。** 主导航永远在左侧，返回只在标题栏，危险操作（退出登录、删除）放在行尾而不是常点的位置。

## 取舍记录

- **不用窄图标侧栏，也不做杂志式大改。** 这两个方向之前已经否决。侧栏保留文字，宽 208px。
- **首页用聚光灯 + 榜单**（2026-10 改版）。榜单 #1–#8 在右侧列出，点击切换聚光灯；聚光灯也能左右翻。之前的整排大海报横栏已取消。
- **今日更新只按时间判断是否更新。** 播出时间早于当前时间即标为“已更新”，不去查询资源是否真的发布，避免额外网络请求。
- **字体用思源柔黑（Resource Han Rounded）。** 圆体比微软雅黑更柔和，符合番剧应用的气质；代价是安装包增加约 28MB（只打包 Regular 和 Bold 两个字重）。
