# 共用组件

新界面优先组合下面这些组件；需要新组件时，先确认它会在两个以上的地方用到，再放进 `lib/ui/core/`。

## 容器

| 组件 | 文件 | 用法 |
| --- | --- | --- |
| `PageScroll` | `page_widgets.dart` | 普通页面的滚动容器，自带左右边距 |
| `MelonPanel` | `page_widgets.dart` | 白色圆角面板；传 `onTap` 后整块可点 |
| `SectionTitle` | `page_widgets.dart` | 区块标题：图标、标题、副标题、右侧操作；`top` 控制上方留白，页面第一个区块用 0 |
| `EmptyState` | `page_widgets.dart` | 空、出错、无结果；必须说明原因，能补救时给一个操作 |
| `SettingRow` | `settings/settings_page.dart` | 设置行：左边标题和说明，右边控件 |

## 海报与封面

| 组件 | 用法 |
| --- | --- |
| `SubjectCover` | 所有封面图都用它：加载中和缺图时显示 `ArtPlaceholder` |
| `ArtPlaceholder` | 人物（角色、声优、制作人员）头像的统一占位：中性底色上按主题着色的“透明阿卡林”线稿，占位框的 80%，不用彩色渐变，避免空位抢颜色 |
| `CoverPlaceholder` | 番剧封面没有、未加载完或加载失败时的统一占位：`surfaceContainerHigh` 底色上一个淡色 `hide_image` 图标（随尺寸缩放，14–44px）。几乎纯色（如 Bangumi 的空白上传）的封面也按缺失处理 |
| `SubjectPoster` | 竖版海报卡，番名压在封面底部；`badge` 用于“今日更新”这类强调标签 |
| `SubjectPosters` | 网格（搜索结果、追番）或横栏（`horizontal: true`） |
| `HorizontalPosters` | 横向滚动栏，悬停边缘时出现翻页按钮；可混排不同卡片 |

海报的悬停效果只作用在封面上，不染色下方的文字区。

海报下方信息行（`PosterMeta`）左侧的星标统一展示番剧公共评分（`Subject.score`，一位小数，缺失时“—”）。只有追番选了“按我的评分”时（`personalScore`）才换成个人评分：`secondaryContainer` 底的小胶囊，写“我的 ★ 8”（整数，未评分“—”），切换时 150ms 淡入淡出；文字、底色、小数位三处都和公共评分不同，避免把个人评分误当公共评分。

`SubjectPosterGrid` 的条目顺序或集合变化时，留下的海报 220ms 滑到新格子，新出现的淡入并上移 10px（按行错开最多 100ms），移动超过三行的直接在新位置淡入；只有变化后 300ms 内建出的海报才淡入，滚动进来的不动画。

## 标签与状态

- `MelonBadge`：彩色小标签，底色是颜色的 13%（深色 20%）透明度。用于平台、季度、集数、“在追”；不指定颜色时用主题的 `accentOf(context).accent`。
- 封面上的标签用实色底和白字（排名、继续观看的“第 N 话”、“今日更新”）。
- 资源标题标注：集数标签在最前面，用主色容器；集数冲突用错误色容器；其余标注用浅灰底；时长、联合署名、下载进度等补充信息用无底色标签；“可能匹配”“最近播放失败”“画质不确定”等需要留意的用 tertiary 容器。

## 控件

| 组件 | 用法 |
| --- | --- |
| `FilledButton` | 每个区域最多一个主要操作（搜索、下载、登录） |
| `OutlinedButton` | 次要但重要的操作（退出登录、立即同步） |
| `TextButton` | 链接式操作（“全部追番 →”“时间表 →”“清除筛选”） |
| `MelonSegmentedControl` | 2–5 个互斥选项，例如画质、收藏状态 |
| `MelonChoiceMenu` | 选项较多或较长的单选，例如设置里的下拉 |
| `MelonFilterMenu` | 可多选的筛选下拉：按钮写“名称 · 已选摘要”，有筛选时用主色容器填充；菜单里每项带勾选框和结果数，勾选后菜单不关闭，底部给“清除” |
| `FilterChip` | 单个布尔开关，例如“本周更新” |
| `Switch` | 布尔设置 |

资源站筛选：菜单里每个站显示结果数或“搜索中 2/5”；搜索失败或部分名称失败时，文字用 tertiary 黄色，按钮上同时出现警示图标。

下载按钮是分体按钮：左边按默认方式下载，右边箭头打开“下载方式”菜单，两种方式都列出，默认方式标“默认”，已加入的标“已加入”。两部分共用一个主色容器底和 12 圆角，中间用一条细分隔线。

## 反馈

- `ActionFeedback` + `FeedbackButton`：刷新、同步这类操作，在按钮原位显示进行中 / 已完成。
- `FeedbackIssue`：操作失败时在区块顶部给出原因和重试。
- 全局 `SnackBar` 只用于没有固定位置的错误。
